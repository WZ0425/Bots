# Cloud agent handoff

## When
Complex coding, repo work, multi-file lab tooling, or Win says use cloud agents.

## Steps
1. Main hands the job to Cursor · Cloud Agent Orchestrator (not every bot launching ad hoc).
2. Brief: goal, repo/paths, constraints, success criteria, model preference if Win named one.
3. Orchestrator scopes, launches, steers, tracks PRs/runs.
4. On completion, Main (or owner) delivers artifacts to Win; prefer attaching files/PDF as relevant.

## Rules
- Do not bypass Orchestrator for “complicated/complex” work Win already assigned that way.
