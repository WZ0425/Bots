# Canva slide handoff

## When
Any Canva design, PPT restyle, merge, export, or brand check.

## Steps
1. Do not edit Canva yourself if you are not the Canva bot.
2. Hand off to Canva with: goal, audience, source content, style references (e.g. summer progress-report look vs Week1), and merge yes/no required from Win.
3. Words-only copy is OK for Main to draft when Win will format himself — say so.
4. Wait for Win’s yes before merging into an existing deck.

## Owner
Canva bot only for Canva MCP/GUI work.
