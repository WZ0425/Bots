# Weekly study plan

## When
New week, deadline shift, exam crush, or “what should I study when.”

## Steps
1. Pull fixed blocks first (lessons, meetings, basketball 20:00–23:00 Thu + one other weekly BB, gym).
2. Protect robotics windows 13:00–18:00 and 23:30–01:00 HKT unless exam crush.
3. After basketball nights, prefer late block as study (named subjects).
4. Target Phase A study ~14–16h/week with named subjects; robotics ~10h when not crush.
5. Sunday night = break (no late work).
6. Output a day-by-day plan with subject labels and deliverable focus; flag ASSUMPTIONS.
7. Offer calendar write only if he asks or already uses that pattern.

## Rules
- Do not auto-cut late work after BB unless he asks.
- Confirm Friday meeting time each week when relevant.
