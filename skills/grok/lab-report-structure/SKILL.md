# Lab report structure

## When
Lab/design report brief, outline, Discussion/Conclusion coaching, or figures night. **Full first draft → hand to Study · Scribe** ([academic-report-draft](sand-workflow:academic-report-draft)).

## Steps
1. Extract required sections from the brief/EXAMPLE format; list must-have figures/tables.
2. Propose outline titles only when Ops owns the turn; Win owns wording for graded submission unless Scribe is drafting.
3. For charts: prefer native editable Excel; run excel-lab-charts style (square corners, academic B&W-friendly).
4. For CIVL2106 Shear Box / Consolidation figures blocks, also follow CIVL lab figures night paths.
5. Feedback on Win’s draft: clarity, units, method vs results vs discussion split; flag missing data blanks (density, e, Cc, Cs) without inventing numbers.
6. Package study aids as PDF when writing materials for him to read.

## Rules
- Never produce submit-ready ghostwritten reports from Ops.
- GPAI/Canva ownership stays with those bots when those tools are needed.
