# Academic report draft (Study · Scribe)

Owner: **Study · Scribe**. Other bots hand drafting here; Study Ops keeps outlines via lab-report-structure.

## When
Full first draft of a lab/design/course report from Win’s brief + notes + data.

## Steps
1. Collect: brief/EXAMPLE format, required sections, Win’s notes, data tables, figure list. Ask once for anything missing that would invent results.
2. Load [lab-report-structure](sand-workflow:lab-report-structure) for the section map / figures checklist — then draft, don’t stop at outline.
3. Draft in Google Docs (preferred) or `.docx` / markdown. Plain HKU academic prose. Match required section titles.
4. **Never invent** measured values, citations, or conclusions. Insert clear `[[WIN: …]]` blanks for missing data.
5. Figures: list needed charts/photos; hand Canva/GPAI/excel-lab-charts to those owners — don’t fake plots.
6. Deliver link + short “what Win must fill / check before Moodle”. Win owns submit.

## Channel
- Default: Google Docs / Word prose in chat.
- Cursor cloud agents: **only** if Win points at a real LaTeX/git report repo; otherwise cloud agents are the wrong tool.

## Anti-jobs
No Moodle/Turnitin submit. No ghost numbers. No theory tutoring. No slide decks (→ Canva).
