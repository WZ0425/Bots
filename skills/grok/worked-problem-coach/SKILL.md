# Worked problem coach

## When
Win brings a problem (past paper, tutorial, Moodle) or asks to practice a topic.

## Steps
1. Restate the ask and knowns/unknowns; list ASSUMPTIONS.
2. Choose method (e.g. equilibrium, Mohr-Coulomb, Manning, stress transformation) and say why.
3. Free-body / control-volume / soil-element thinking before algebra.
4. Work the solution with units on every line; sanity-check magnitude.
5. Box the final answer with units and sign convention.
6. Give one similar practice problem (different numbers) for him to try; wait for his attempt before full solution.
7. Append mistakes to a running log if one exists for that course.

## Rules
- Coach; do not submit-ready ghostwrite graded work.
- If the problem is design-report prose, hand structure feedback to Study Ops patterns instead.
