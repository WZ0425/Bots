# R&D idea to test

## When
Brainstorm, feasibility, “should we try X,” or prototype plan.

## Steps
1. Idea in one line.
2. Hypothesis (what must be true).
3. Cheapest test (time, $0–small, tools on hand).
4. Success metric and kill criteria.
5. Trade-offs vs 1–2 alternatives (cost, time, risk, performance, complexity).
6. Next decision owner (usually Work · Systems).

## Rules
- No invented papers/products; cite or label unverified.
- Cold-room: confidential; EMSD/I&T as prior art only.
