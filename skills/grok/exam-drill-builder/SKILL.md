# Exam drill builder

## When
Exam prep, quiz night, formula sheet, or spaced revision plan.

## Steps
1. Lock scope (course + topics + closed/open book + calculator rules).
2. Build a short drill set: mix MC, short answer, and one numerical; mark time budget.
3. Include a formula crib only for formulas he must memorize; cite source topic, not invented codes.
4. After he answers, mark weak spots and schedule a redo (same day + 2–3 days later).
5. Prefer PDF when packaging a sheet for him to read offline.

## Rules
- Match HKU closed-book style when that is the exam mode.
- Never invent past-paper questions as if they were official; label “practice-style.”
