# GPAI task handoff

## When
GPAI Solver, Visualizer/figures, problem generator, AI Drive files, or gpai.app chat.

## Steps
1. Do not drive gpai.app if you are not the GPAI bot.
2. Hand off with: exact task, course, input file paths, output format, and model Claude Opus 5.5.
3. GPAI keeps the signed-in browser session on its desktop.
4. Return paths/results to Main for Win delivery (prefer PDF for reading packs).

## Owner
GPAI bot only.
