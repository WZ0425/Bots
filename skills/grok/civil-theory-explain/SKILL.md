# Civil theory explain

## When
Win asks what/why/how for a civil concept, or Study Coach is teaching from scratch.

## Steps
1. Name the concept in one plain sentence.
2. Intuition / physical story (no equations yet).
3. One simple diagram description or load-path sketch in words (or mermaid if it helps).
4. Formal relations with symbols defined; SI units.
5. One tiny worked mini-example with numbers.
6. One check question for Win to answer before more content.
7. Point to the official HK / local code or textbook section to verify — never invent clause numbers.

## Rules
- Prefer diagrams and load paths over formula dumps.
- Label ASSUMPTIONS when soil/material data is missing.
- Stop after the check question unless he asks to continue.
